Bienvenido a Solwed OS

¡Gracias por instalar Solwed OS!


Solwed OS es una distribución de Linux basada en Ubuntu, personalizada, diseñada para ser familiar y fácil de usar, ya sea que procedas de Windows o macOS. Aprovecha el sólido ecosistema de software de Ubuntu con un acabado adicional pensado para el escritorio. ¡No podemos esperar para mostrarte todo!
