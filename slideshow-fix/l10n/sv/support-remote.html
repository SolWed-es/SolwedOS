Support bara ett klick bort

När du behöver hjälp behöver du inte förklara problemet i telefon eller vänta på ett besök. Solwed OS levereras med RustDesk, klart att använda: öppna det från startmenyn, dela ID:t och lösenordet som visas, så ansluter vårt supportteam direkt till din dator — endast med ditt tillstånd, aldrig utan det.

Vi kör vår egen server istället för RustDesks publika server, så anslutningarna blir snabbare och beror inte på någon annan. Det är som att ha någon från supporten sittandes precis bredvid dig, utan att de behöver resa.
