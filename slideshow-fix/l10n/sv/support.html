Hjälp och support

Om du har frågor eller stöter på ett problem finns Solweds supportteam här för dig på solwed.es/contacto.

På Ask Ubuntu kan du söka efter och fråga om mycket vanliga problem. Lösningarna för nästan alla Solwed OS-problem är identiska med lösningarna för Ubuntu. Du kan helt lita på Ubuntus dokumentation och expertis för att lösa problem med Solwed OS.
