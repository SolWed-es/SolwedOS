Bem-vindo ao Solwed OS

Obrigado por instalar o Solwed OS!


O Solwed OS é uma distribuição Linux personalizada baseada no Ubuntu, projetada para ser familiar e fácil de usar, seja você migrando do Windows ou do macOS. Ele se apoia no vasto e sólido ecossistema de software do Ubuntu, com um acabamento extra para o ambiente desktop. Mal podemos esperar para mostrar por aqui!
