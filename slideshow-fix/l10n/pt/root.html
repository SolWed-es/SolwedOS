Acesso Total, Código Aberto

O Solwed OS é construído sobre software de código aberto licenciado pela GPL, permitindo que qualquer pessoa inspecione e modifique o sistema a qualquer momento.

O Solwed OS oferece aos usuários controle total sobre seus computadores. Por padrão, os usuários recebem privilégios de root. Você pode executar qualquer comando a qualquer momento usando o comando sudo. Os usuários sempre possuem o mais alto nível de controle sobre seus computadores.
